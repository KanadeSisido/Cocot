# Cocot - 没入型音声共通基盤(alpha)

Cocot - 没入型音声共通基盤 はASMR音声特化型の音声配信プラットフォームです。

## 目的

ASMR音声配信に特化し、ASMR音声の制作、配信、視聴をより快適にすること、およびクリエイターの収入安定化により、ASMR文化の発展に寄与することを目的としています。

## 特徴

- ASMR音声に特化した機能の提供
- 音声体験の向上を目指したUI/UX設計
- クリエイターの収入安定化を支援する仕組みの導入

## 技術スタック

- フロントエンド：Next.js
- バックエンド：
  - Webバックエンド：Go, Echo
  - データベース：MariaDB、Redis
  - 補助オブジェクトストレージ：Garage
  - メインオブジェクトストレージ：Cloudflare R2
