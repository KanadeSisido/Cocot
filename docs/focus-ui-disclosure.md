# 音完全集中UI：画面を見ずに操作する音声再生UIの技術公開

- 公開者：Kanade Sisido（Cocot）
- 初版：2026-10-07
- 版：1

この文書は、Cocotの音声再生UI「音完全集中UI」（以下、集中モード）の仕組みを、公開日の時点で存在した技術として記録し公開するものである。ここに書いた内容と変形例を含む。

設計は継続中であり、決まった内容を版として追記していく。以下の数値は、特に断りのない限り実機での試用に基づく初期値であり、同じ仕組みは別の数値でも成り立つ。

## Abstract (English)

A mobile audio player UI for listening to audio works (e.g., ASMR) without revealing what is being played and without looking at the screen. In "focus mode" the screen shows nothing (black), and the OS media controls show only a generic title. The listener prepares several "rails" in advance, each backed by a content source (e.g., newest works, a tag). One-finger and two-finger gestures on the blank screen switch rails (vertical swipe on one side), adjust in-app volume (vertical drag on the other side), seek, move between works, and toggle playback. Each rail keeps its own current work, each work keeps its own resume position, and a rail continues into sequential recommendations when its source is exhausted. Gesture recognition uses a side split decided at touch-down, a dead zone along the split for vertical gestures, a configurable split position (one-handed mode), a bottom dead zone to avoid conflicts with OS swipe-up gestures, and cancellation of a rail switch by reversing the swipe before release. When the audio output route is the device's built-in speaker, focus mode refuses to start playback or raise the volume (optionally signalling the refusal with a dedicated vibration pattern), while the normal UI warns and performs the action only if it is repeated within a short time.

## 1. 目的

周囲に聴いている作品を知られずに、画面を見ないまま音声作品を選び、再生を操作できるようにする。満員電車のように画面をのぞかれやすい場所や、夜間に明るい画面を見たくない場面を想定する。

## 2. 表示しないこと

- 集中モードの画面は全面を黒にし、作品名・サムネイル・操作アイコン・音量ゲージ・操作の結果を示す表示を出さない。操作の結果は、音が変わること（作品が変わる、位置が飛ぶ、音量が変わる）で伝える。
- OSのメディア表示（通知、ロック画面、コントロールセンター等）には、全作品で共通の汎用の題名だけを渡し、作品名とサムネイルを渡さない。OSによって消せないアプリ識別表示は許容する。
- 集中モード中はステータスバーとナビゲーションバーを隠せる。
- 長押しをしたときに限り、レールの位置を示す点の列、再生位置のバー、通常の画面へ戻るボタンを暗い色で表示する（7.5節）。作品名は表示しない。

## 3. 再生ソースとレール

- **再生ソース**：再生する作品の集合。例として、全公開作品を新しい順に並べた「新着」と、指定したタグが付いた作品の集合がある。
- **レール**：ユーザーが再生前に並べておく、再生ソースに沿った再生の列。複数のレールを縦に並べ、集中モードでは上下の操作でレールを乗り換える。
- 乗換は循環しない。並びの端でさらに乗り換えようとしても、レールも作品も変わらない。音が変わらないことが、端に着いたことの合図になる。
- 各レールは自分の**現在の作品**を持ち、端末に保存する。
  - 初めて乗るレールでは、ソースの先頭から見て最初の、聴き終えていない作品から再生する。
  - 戻ってきたレールでは、離れたときの作品を、その作品の保存位置から再開する。
  - 乗換先の作品がいま流れている作品と同じ場合は、その次の作品から再生する。音が変わらないと乗換に失敗したように聞こえるため。
- 一時停止中に乗り換えたり作品を移ったりしたら、再生を始める。
- レールを進むとき、聴き終えた作品は飛ばし、途中まで聴いた作品は保存位置から再開する。
- ソースの作品が尽きたら止めず、聴いた作品とその順序をもとに次の作品を選ぶ推薦（系列推薦）で列を延ばす。ソースが空の場合も、乗換を成立させて推薦の作品を流す。
- 新しく公開された作品は、レールに乗ったときにソースを読み直して見つけ、現在の作品の直後に差し込む。
- 一覧から作品を選んで再生したとき、その一覧に対応するレールがあればそのレールに乗る。対応するレールがない場合（検索結果など）は、選んだ作品から始まり推薦で延びる**一時レール**を作り、並びの先頭に置く。
- プレイヤーを閉じたら、全レールの現在の作品をリセットする。作品ごとの再生位置と聴き終えた印は残す。

## 4. 再生位置と作品の視聴状態

- 再生位置は作品ごとに1つ持ち、同じ作品が複数のレールに入っていても共通にする。端末に保存し、アカウントには紐付けない。
- 作品の状態は「未再生」「途中」「完聴」の3つとする。
  - 作品を離れたときの位置が先頭から10秒未満なら、保存位置を消す。
  - 自然に最後まで再生したとき、または長さの95%以上の位置で離れたときに完聴とする。
- 作品を離れたとき、一時停止したとき、アプリが背面に移ったとき、および再生中に定期的に（例：10秒ごと）位置を保存する。

### 4.1 「前」の2段階動作

- 「前」の1回目は、その時点の位置を退避して、現在の作品の先頭へ戻る。
- 1回目から5秒以内に2回目を行うと、前の作品へ移る。元の作品には退避した位置を保存する。先頭に戻った後の数秒で上書きしない。
  - 例：12分の位置で1回目、5秒以内に2回目を行って前の作品へ移った場合、元の作品へ戻ると12分から再開する。
- 5秒の待機が切れたとき、または待機中にシーク・次の作品・レール乗換をしたときは、先頭から聴き直す意図とみなし、退避位置を捨てる。音量の調整は待機に影響しない。

### 4.2 道のり

- 各レールは、ユーザーに見せない**道のり**（そのレールで再生した作品の列と、現在位置を示すカーソル）を持つ。
- 「前」はカーソルを1つ戻すだけで、推薦をやり直さない。道のりの先頭では、ソースの並びで1つ前の作品へ戻る。道のりは過去50作品まで持つ。
- 推薦は、同じレールの道のりにある作品を候補から外す。

## 5. 音量

- 端末の音量とは別に、アプリ内の音量（0〜100%）を持ち、端末の音量に掛け合わせる。100%を超える増幅はしない。
- 集中モードの縦ドラッグと、通常の画面の音量スライダーは同じ値を操作する。

## 6. 集中モードのジェスチャー

画面を左右の2つの側に分けて使う。左右の役割は入れ替えてもよい。

### 6.1 割り当て A（タップ系）

| 入力 | 動作 |
| --- | --- |
| 右側をダブルタップ | 10秒進む |
| 左側をダブルタップ | 10秒戻る |
| ダブルタップでシークした直後（例：1秒以内）のシングルタップ | 同じ向きにさらに10秒シークする（連続タップで20秒、30秒と重ねる） |
| 1本指で横スワイプ | 次の作品／前（4.1節の2段階動作） |
| 左側で上／下スワイプ | 次／前のレールへ乗換 |
| 右側で上／下ドラッグ | アプリ内音量を連続して調整 |
| シングルタップ | 再生／一時停止 |
| 長押し | 7.5節の表示を出す |

### 6.2 割り当て B（スワイプ系）

| 入力 | 動作 |
| --- | --- |
| 1本指で横スワイプ | 10秒進む／戻る |
| 2本指で横スワイプ | 次の作品／前（4.1節の2段階動作） |
| 左側で上／下スワイプ | 次／前のレールへ乗換 |
| 右側で上／下ドラッグ | アプリ内音量を連続して調整 |
| ダブルタップ | 再生／一時停止 |

### 6.3 横の向き

- 右から左へ動かすと「進む」（10秒進む、次の作品）、左から右で「戻る」とする。表示中のものを脇へどかすと次のものが右から入ってくる、写真の一覧やページめくりと同じ向きである。縦の「上へスワイプで次のレール」と同じ捉え方になる。
- 逆の向き（左から右で進む）も設定で選べる。

## 7. ジェスチャーの判定

### 7.1 縦と横の判定

- OSやフレームワークの縦・横ドラッグ認識に任せず、指の座標を直接読んで判定する。2本指の操作を同じ仕組みで扱うため。
- 指が一定距離（例：18dp）動いた時点で、横と縦の移動量の大きいほうを主軸とする。
- 主軸の方向に一定距離（例：40dp）以上動かして離したときだけ操作を成立させる。それより短ければ何もしない。

### 7.2 左右の判定と操作無効領域

- 左右は、指を置いた位置で決める。ジェスチャーの途中で境界をまたいでも変えない。
- 境界を中心とした一定幅（例：48dp）の帯から始めた縦の操作は無視する。左右で意味が変わるのは縦の操作だけなので、横の操作は帯から始めても受け付ける。割り当て A のダブルタップも、帯の中なら無視する。左側のレール乗換と右側の音量の取り違えや、意図しない音量の急上昇を防ぐ。
- 境界の位置は固定せず、設定で動かせる（例：幅の25〜75%）。片手で持つときに、親指の届く範囲に合わせて左右の広さを変える（片手モード）。操作無効領域も境界に合わせて動く。

### 7.3 画面下端の操作無効領域

- 画面の下端から一定の高さ（例：64dp）は、タップもスワイプも受け付けない。OSの「下からのスワイプでアプリを閉じる・切り替える」操作と競合させないため。

### 7.4 レール乗換の確定と取消

- レール乗換は指を離したときに確定し、動かしている途中では乗り換えない。通り過ぎたレールの状態を変えないため。
- スワイプ中に一番遠くまで動かした位置を記録し、そこから逆向きに一定距離（例：40dp）以上戻してから離したら、乗換を取り消す。戻した距離がそれより短ければ、一番遠くまで動かした向きで乗り換える。

### 7.5 長押しの表示

- 長押しで、レールの位置を示す点の列、再生位置のバー、通常の画面へ戻るボタンを表示する。
- 表示はシングルタップで消すまで出し続ける。表示を消すためのシングルタップは、再生／一時停止を行わない。

### 7.6 2本指の操作

- 1本目の指で主軸が決まる前に2本目の指を置いたときだけ、2本指の操作とする。2本の指の重心の動きで判定する。
- どちらかの指を離した時点でジェスチャーを終え、残った指の動きは無視する。

## 8. 通常の画面との共通化

- 通常の画面（作品名やジャケット画像を表示する再生画面）でも、集中モードと同じ再生の規則（3〜5節）を使い、入力手段だけを変える。
- 通常の画面でも、画面の上半分（レールの点の列を除く）で集中モードと同じジェスチャーを受け付ける。下半分にはボタン（前、10秒戻る、再生／一時停止、10秒進む、次）、シークバー、音量スライダーを置く。
- 「前」のボタンも4.1節の2段階動作に従う。
- レールの乗換は、画面の左端に縦に並べた点の列を押さえ、指を上下に動かして、離したときに指の位置のレールへ乗り換える。点の列から指を横に大きく外して離したら取り消す。
- ジェスチャーでシークしたときに限り、スワイプした側に「+10」「-10」を短く表示し、続けてシークしたら「-20」のように合計を表示する。

## 9. その他

- イヤホンが外れたら一時停止する。スピーカーから音が流れるのを防ぐため。
- 振動や効果音による操作の通知は、使うかどうかを選べる。

### 9.1 本体スピーカーへの出力

音声の出力先が端末本体のスピーカーである状態での、次の操作を対象にする。

- 再生を始める操作（再生、一時停止からの再開、再生を始めるレール乗換や作品の移動を含む）
- アプリ内音量を上げる操作

**集中モード**では、本体スピーカーへの出力を受け付けない。上の操作は、何度繰り返しても実行しない。集中モードは周囲に聴いている作品を知られないための状態であり、スピーカーで鳴らすことは想定しないため。

- 振動をオンにしている場合は、操作を受け付けなかったときに「スピーカー出力を受け付けない」ことを示す専用の型で振動する。振動は補助であり、気づかれなくても音が出ないことは変わらない。
- 音はスピーカーから出てしまうので使わず、画面にも表示しない。

**通常の画面**では、上の操作をしようとしたら、実行せずに警告する。

- 作品情報を含まない短い文言（例：「スピーカーから再生されます。もう一度押すと再生します」）を表示する。
- 警告してから一定時間（例：3秒）以内に同じ操作をもう一度したら、意図した操作とみなして実行する。
- 一度通した操作は、出力先が変わるか、プレイヤーを閉じるまで、再び警告しない。再生と音量上げの許可は別々に扱う。

出力先は、OSが報告する現在の出力経路（有線イヤホン、Bluetooth機器、本体スピーカーなど）で判定する。

## 10. 変形例

以下の変形例も、この文書で公開する技術に含む。

- 作品の移動を、次のいずれかの操作に割り当てる。
  - 横スワイプの後、指を離さずに止めて一定時間（例：0.5秒）保持する。止めたかどうかは、一定時間指の更新が来ないこと（小さな揺れは許容する）、または移動速度が閾値を下回ることで判定する。
  - 一定距離（例：220dp）以上の長い横スワイプ。境界を越えたとき、または戻したときに振動で知らせ、離す前に結果が分かるようにする。
  - 離す瞬間の横の速度が閾値（例：1200dp/s）以上の速いフリック。
  - 2本指の横スワイプ（割り当て B）、または1本指の横スワイプ（割り当て A）。
- レールの乗換を、指を離したときではなく、一定距離に達した瞬間に確定する。
- 左右の判定を、指を置いた位置ではなく、主軸が決まった位置で行う。
- 長押しの表示に代えて、シングルタップで表示を出し、一定時間（例：3秒）で自動的に消す。
- 左右の役割、上下の向き、横の向きを入れ替える。
- 再生ソースとして、声優、マイリスト、後で見る、複数タグの組み合わせなどを使う。
- 推薦として、タグや声優の意味的な近さを使う。
- 集中モードでも本体スピーカーへの出力を拒まず、通常の画面と同じく、振動で警告して一定時間内にもう一度操作したら実行する。振動をオフにしている場合だけ受け付けない。
- 本体スピーカーへの出力の警告や拒否を、再生と音量上げのどちらか一方だけに適用する。
